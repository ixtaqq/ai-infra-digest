## Highlights

- The SEC stage now reads real filing numbers. It drops hidden iXBRL data, leads earnings filings with the EX-99 exhibit, and tracks Form 6-K for TSM, ASML, and ARM. None of the 64 editions published before this release contains an extract.
- Stock quotes now use the prior session close. The 1,307 rows stored before the fix all show 0% change.
- pg_cron now dispatches the delivery and digest workflows, and GitHub's own crons stay as a backstop. GitHub had been running the 10-minute delivery cron about every 4.4 hours and starting the digest cron 1.8 to 3.7 hours late.
- Publication now starts at 06:17 MYT, ahead of the default 08:00 delivery. A successful digest run triggers a delivery catch-up.
- The Telegram digest leads with a TL;DR, lists top movers one per line, and numbers stories with linked titles. SEC highlights show the highest-impact extracts first.
- Scheduler runs count each slot as delivered, held, waiting, or failed, so a held slot no longer fails later runs. Five new quality alerts cover flat prices, thin editions, missing SEC extracts, held deliveries, and late deliveries. `npm run operations -- release-editorial` releases a stuck editorial claim and records an audit row.
- Other fixes cover six SEC CIKs, RSS keyword matching and dates, `/stop` and `/watchlist` parsing, Slack and Telegram escaping, `search_articles` for anonymous readers, and the dashboard's 14-day window and thesis ordering. Articles are now marked seen only after the AI analyzes them.
- A new editorial review set holds 50 real RSS excerpts with offline quality gates. All 50 await human review, so this release makes no editorial accuracy claim.
- Nodemailer, zod, and openai were upgraded. GitHub Actions are pinned to commit SHAs, and Dependabot is configured.
