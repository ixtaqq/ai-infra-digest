// 01 · THE BRIEF

One digest.Zero noise.

RELEVANCE GATE

Every article is scored 1–10 for AI-infra relevance. When optional embeddings are enabled, a semantic gate checks 20 canonical seeds too; otherwise the pipeline uses its lexical fallback.

TRUST-WEIGHTED RANKING

Vote-learned source multipliers, editorial tiers (1.2× Reuters/WSJ, 0.8× vendor PR), PR-wire dampening and 48h novelty decay decide the order.

MULTI-CHANNEL

Telegram, Slack and Gmail fan out in parallel at your preferred time — Slack or email failures never block Telegram.

// 02 · CAPABILITIES

Full value chain coverage.

From semiconductor manufacturing to power utilities — every layer of the AI infrastructure stack monitored daily.

FEEDS📡

RSS News Collection

68 feeds across 10 sectors — NVIDIA and TSMC to Vertiv and Constellation Energy. Conditional GET caching, retry with jitter, auto-skip for dead feeds.

CORE🧠

Two-Tier AI Routing

Classification on a fast 8B model, synthesis on a strong 70B model. Saves 40–60% on AI cost — about 3,000 tokens per day in total.

SEC🏛️

SEC Two-Pass Extraction

Free keyword pre-filter → fast-model flagging (~$0.0005) → strong-model extraction (~$0.01). Capex, AI revenue, margins and guidance from 35 companies.

OPTIONAL🎙️

Earnings Transcript Mining

When a Roic.ai key is configured, transcripts for 15 AI companies receive topic segmentation, guidance extraction, QoQ delta, and management tone.

MARKET📊

Stock & Market Data

Yahoo Finance snapshots for 30+ tickers, stored daily. Tracks price deltas and sector rotation for every mentioned stock.

LAYER📈

Intelligence Layer

Materializes daily_derived_metrics every run. Market Pulse surfaces WoW movers ≥ 20%; /trends NVDA 30d renders a Unicode sparkline.

TRUST⚖️

Trust-Weighted Ranking

👍/👎 votes learn per-source multipliers. Cosine-similarity corroboration boosts stories confirmed by several outlets; ⚠️ bear cases challenge the rest.

OPTIONAL🔢

Embeddings + pgvector

When an embedding key is configured, OpenAI vectors in Supabase enable semantic corroboration and relevance gating. Without one, URL/Jaccard fallbacks keep the pipeline running.

SHIP🖥️

Premium Live Dashboard

Graphite + copper terminal UI. Public read-only deployment config, 6 charts, SEC filings table, full-table search, expandable rows with bear cases, auto-refresh every 60s.

PHASE VIISHIPPED

Sharper Signal

// 06 · SETUP

Run it in 5 minutes.

All you need is a Telegram bot token and a Groq API key (free tier). No credit card required.

analyst@stack: ~/ai-infra-digest
# Clone & install
$git clone https://github.com/ixtaqq/ai-infra-digest.git
$cd ai-infra-digest && npm install
 
# Add your API keys
$cp .env.example .env && nano .env
 
# Run the full pipeline
$npm run dev
 
# 336 unit tests, no credentials needed
$npm run test:unit
