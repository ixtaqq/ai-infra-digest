Get Started

Run in 5 Minutes

All you need is a Telegram bot token and a Groq API key (free tier).

# Clone the repository
$ git clone https://github.com/ixtaqq/ai-infra-digest.git
$ cd ai-infra-digest
 
# Install dependencies
$ npm install
 
# Configure environment
$ cp .env.example .env
$ nano .env # Add your API keys
 
# Run the full pipeline
$ npm run dev
 
# Or test with sample data
$ npm run test-digest
 
# Run tests
$ npm test
✓ 58 tests passing
