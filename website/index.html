Capabilities

Full Value Chain Coverage

From semiconductor manufacturing to power utilities — every layer of the AI infrastructure stack monitored daily.

📡

RSS News Collection

57 feeds across 10 sectors — from NVIDIA and TSMC to Vertiv and Constellation Energy. Conditional GET caching minimises bandwidth.

🧠

Two-Tier AI Routing

Classification via fast 8B model (llama-3.1), synthesis via strong 70B model (llama-3.3). Saves 40–60% on AI costs — ~3,000 tokens/day total.

📊

Stock & Market Data

Yahoo Finance price snapshots for 30+ tickers. Tracks changes and sector rotation for every mentioned stock.

🎙️

Earnings Transcript Mining

Fetches earnings calls via Roic.ai API for 15 AI companies. Two-pass AI: topic segmentation (fast) + guidance extraction & tone (strong). QoQ guidance delta with ↑↓ arrows.

🏛️

SEC Two-Pass Extraction

Keyword pre-filter (free) → fast model flagging (~$0.0005) → strong model extraction (~$0.01). Capex, AI Revenue, Margins, Guidance from 35 companies. 🏛️ badge on filing articles.

📈

Intelligence Layer

Materializes a daily_derived_metrics table every run. "What Changed" Market Pulse block in each digest shows WoW mention movers ≥20%. /trends NVDA 30d renders a Unicode sparkline + delta.

⚖️

Trust-Weighted Ranking

Vote-learned source multipliers from 👍/👎 feedback. Static editorial tiers (1.2× for Reuters/WSJ, 0.8× for vendor PR). Corroboration boost (+5% per extra source) now uses cosine similarity for smarter story clustering. ⚠️ Bear cases for high-impact articles.

🤖

Telegram Bot + Digest

Delivered at your preferred time with /digest, /trends, /sec, /sources quality commands. 🏛️ SEC badges + 🎙️ Earnings Watch + 📊 Market Pulse + ⚠️ bear cases included.

🖥️

Premium Live Dashboard

Graphite + copper terminal UI. Auth gate, 6 charts, SEC filings table, full‑text search, expandable article rows with bear cases and thumbs scores, auto-refresh every 60 s.

Get Started

Run in 5 Minutes

All you need is a Telegram bot token and a Groq API key (free tier). No credit card required. Two-tier AI routing saves 40-60% on costs.

# Clone & install
$ git clone https://github.com/ixtaqq/ai-infra-digest.git
$ cd ai-infra-digest && npm install
 
# Add your API keys
$ cp .env.example .env && nano .env
 
# Run the full pipeline
$ npm run dev
# Or test with sample data
$ npm run test-digest
 
# 84 unit tests, no credentials needed
$ npm run test:unit
✓ 84 unit tests passing
